# 13.00 Index des ADR

Chaque décision structurante est tracée dans un ADR, avant d'écrire le code qui en dépend (epic `decisions`).

## Règles

- Un fichier par décision : `13.xx Titre court.md`, en prenant le prochain identifiant libre.
- Partir du modèle [[01.01 Modèle ADR]].
- Statuts : `proposé` → `accepté`, puis éventuellement `remplacé par 13.xx` ou `abandonné`.
- Un ADR accepté n'est plus modifié sur le fond : une nouvelle décision fait l'objet d'un nouvel ADR qui le remplace.
- La décision est reportée dans le [[11.01 Cahier des charges]].
