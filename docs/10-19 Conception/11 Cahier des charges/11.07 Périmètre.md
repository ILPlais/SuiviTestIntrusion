# 11.07 Périmètre

Le périmètre se compose de **sous-modules atomiques**, activables test par test. Les réponses au [[11.05 Engagement#Questionnaire d'engagement|questionnaire d'engagement]] proposent l'activation (par exemple, « Des réseaux Wi-Fi font-ils partie du périmètre ? » = oui → *Radio*) ; le chef de projet la confirme.

## Objets du périmètre

Tout objet du périmètre (machine, application, ressource, site, cible, etc.) porte :
- Inclus ou exclu, avec un commentaire ;
- Plages horaires interdites et contraintes de disponibilité ;
- Liens vers les tâches et les vulnérabilités qui le concernent.

Les **secrets** (mots de passe des utilisateurs, comptes de test, clés d'accès) sont chiffrés dans le navigateur comme les preuves ([[13.01 Format de chiffrement des preuves]]) : le serveur ne les voit jamais en clair.

## Réseau

- Machines (IP, noms, etc.) ;
- Services ;
- Utilisateurs (noms, mots de passe, informations, etc.).

**Diagramme du réseau** créé avec [Mermaid](https://mermaid.js.org/).

## Applications

- Type : web, API ou mobile ;
- Nom, URL ou identifiant de paquet, version ;
- Environnement (production, préproduction, recette) ;
- Plateformes et versions minimales (mobile) ;
- Documentation fournie (OpenAPI, GraphQL, collection Postman, code source) ;
- Comptes de test, par rôle ;
- Fonctions exclues ;
- Hébergement : lien vers une machine ou une ressource cloud du périmètre.

## Ressources cloud et SaaS

- Fournisseur (AWS, Azure, GCP, éditeur SaaS, autre) ;
- Type : compte, abonnement ou projet, tenant d'identité, cluster Kubernetes, registre de conteneurs, chaîne CI/CD, service SaaS ;
- Identifiant ;
- Régions, services inclus et exclus ;
- Accès fourni (rôle, compte d'audit) ;
- Autorisation du fournisseur ou de l'éditeur (référence, date) ;
- Contraintes de coût.

## Sites physiques

- Adresse, installation partagée ou non, étages dans la portée ;
- Gardes de sécurité (internes ou employés par un tiers) ;
- Pratiques autorisées : crochetage, hack matériel, vol de matériel (tout matériel ou liste autorisée).

## Radio

- Réseaux Wi-Fi (SSID, emplacement) ;
- Équipements Bluetooth et RFID (badges, lecteurs).

## Ingénierie sociale

- Adresses de courriel autorisées et interdites ;
- Numéros de téléphone ciblés ;
- Objectif d'accès physique et nombre de personnes ciblées.
