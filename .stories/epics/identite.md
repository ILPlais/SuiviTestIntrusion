# Epic: Identité, droits et isolation

**Slug:** identite
**Status:** ready
**Created:** 2026-10-26

## Goal

Authentifier les utilisateurs, appliquer les rôles et ACL, isoler strictement les tenants et tracer toute action sensible (CDC 11.06, 11.02 « Journaux d'audit »).

## Scope

- Auth locale, 2FA par TOTP
- Sessions Sanctum
- Rôles, ACL, multi-tenant
- Audit
- Cycle de vie utilisateur (invitation, désactivation, suppression)

## Out of Scope

- LDAP / Active Directory (V2, story identite-2 conservée)
- OAuth2 / OIDC (V2)
- SMS (V2)
- Jetons API personnels scopés (V2, story identite-4)
