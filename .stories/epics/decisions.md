# Epic: Décisions d'architecture (ADR)

**Slug:** decisions
**Status:** ready

## Goal

Lever les points bloquants et les zones floues du cahier des charges avant d'écrire du code crypto ou d'authentification. Succès : chaque décision est tracée dans un ADR `13.xx` (catégorie 13 Décisions d'architecture) et reportée dans le CDC `11.01`.

## Scope

- ADR format de chiffrement, KDF, LDAP/AD vs coffre, file d'attente, sécurité HTTP, licence, i18n
- Mise à jour du CDC et section Roadmap V1/V2

## Out of Scope

- Implémentation des décisions (epics suivants)
