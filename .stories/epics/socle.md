# Epic: Socle technique

**Slug:** socle
**Status:** ready

## Goal

Disposer d'un squelette Laravel + SPA Vue 3 déployable, testé en CI, qui applique dès le départ les conventions de l'API v1 décrites dans le CDC (11.03, 11.02 « Déploiement »).

## Scope

- Laravel 11+ / PHP 8.3+, Vue 3 + Vite
- Docker Compose, CI, outillage de tests
- Conventions API v1 : erreurs, pagination, rate limiting, OpenAPI, en-têtes de sécurité

## Out of Scope

- Fonctionnalités métier
- Service web HTTPS intégré (V2, story socle-7) : proxy inverse externe en V1
